# Windows и Lazarus

## Статус

Не проверено. На стенде нет Windows, а собранный тулчейн не содержит кросс-компилятора `ppcrossx64`, поэтому даже частичная проверка `fpc -Twin64 -s` здесь невозможна. Код написан так, чтобы компилироваться нативно на Windows. При первой сборке на Windows возможны ошибки компиляции, которых здесь не видно.

Платформенных ветвлений в коде два: имя библиотеки GLFW (`GlfwLibraryName` в `src/app/EngDemo.pas`) и выбор библиотеки в `src/platform/GLFWBind.pas` (`{$IFDEF WINDOWS}`, `{$IFDEF DARWIN}`). Функции OpenGL на Windows получаются через `glfwGetProcAddress` (WGL). Остальное общее.

## Требования

- FreePascal 3.2.2 или новее с RTL для Win64. Компилятор должен работать на Windows; для сборки под Win64 на Linux нужен кросс-компилятор.
- Для запуска окна: GLFW 3, файл `glfw3.dll` (x64) рядом с `Demo.exe`, драйвер видеокарты с OpenGL 4.3 core.

## Сборка из командной строки

```bat
set FPC_EXE=C:\fpc\bin\fpc.exe
build_windows.bat          & rem сборка и тесты
build_windows.bat bench    & rem + бенчмарк
build_windows.bat demo     & rem + Demo.exe в build\win64
```

Сборка идёт без AVX2 (переносимый вариант): `-O3 -Xs -Twin64 -Px86_64`.

## Lazarus

1. Открыть `lazarus\EngineDemo.lpi`.
2. Запуск > Собрать (Run > Build).
3. Запускать из корня репозитория, где лежит каталог `shaders\`, или передать путь аргументом `--shaders`.

Пути поиска модулей в проекте относительные (`../src/...`), поэтому проект работает из любого каталога, пока структура репозитория не меняется. Проект `.lpi` написан вручную и в IDE не открывался.

## Коды возврата и сообщения

| Код | Значение |
|---|---|
| 0 | успех |
| 1 | ошибка окна, контекста OpenGL 4.3 или шейдеров |
| 2 | библиотека GLFW не найдена |

Сообщения на русском языке. Чтобы консоль Windows показывала их правильно, выполните `chcp 65001` перед запуском.
