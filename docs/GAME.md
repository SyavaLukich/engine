# Gunner: шутер от третьего лица на движке

Экшн-шутер от третьего лица с элементами платформинга в духе Super Mario 64. Персонаж стреляет, бьёт ногами,
прыгает, сальтует, бегает по стенам и перилам, висит на уступах. Враги патрулируют, видят игрока, преследуют
его по пути A* и атакуют. Код: `game/src/` (логика, без GL), `game/src/GameRender.pas` (визуал),
`game/src/GameApp.pas` (окно и сценарии), `game/Gunner.pas` и `lazarus/Gunner.lpr` (программы).

## Запуск

**С окном** (нужны GLFW 3 и OpenGL 4.3 core):

```sh
./build.sh examples                 # собирает build/examples/Gunner
./build/examples/Gunner             # Linux: libglfw.so.3 рядом или в системе
```

Windows: `build_windows.bat gunner`, затем `build\win64\Gunner.exe` рядом с `glfw3.dll`. Сборка Windows
на этом стенде не проверялась (нет кросс-компилятора).

**Без окна** (проверено здесь на Mesa 21 softpipe, OpenGL 4.3 через переопределение версии):

```sh
MESA_GL_VERSION_OVERRIDE=4.3 MESA_GLSL_VERSION_OVERRIDE=430 \
  ./build/examples/Gunner --offscreen --osmesa /путь/libOSMesa.so.8 --scenario wallrun --shots out/game
```

Сценарии: `wallrun`, `ledge`, `backflip`, `slide`, `pound`, `combat`. Снимки пишутся как
`out/game_<сценарий>_<тик>.png`, когда состояние мира совпало с целью сценария. Сценарии задают начальные
условия и ввод по тикам, поэтому снимки воспроизводимы.

## Управление (окно)

| Клавиша | Действие |
|---|---|
| W A S D | движение относительно камеры |
| Пробел | прыжок; подряд - двойной и тройной; присед + пробел - сальто назад; бег + пробел - сальто вперёд; боковой шаг + пробел - сальто вбок |
| C или Ctrl | присед: из бега - подкат; в воздухе - удар сверху |
| F | выстрел (в том числе из висения на уступе) |
| E | удар ногой (на земле и в воздухе) |
| R | прицеливание (камера ближе, персонаж смотрит по камере) |
| стрелки | поворот и наклон камеры |
| Esc | выход |

## Враги (ИИ)

- **Пехотинец** (100 HP). Зрение: дальность 26 м, поле зрения 130 градусов, проверка линии видимости лучом
  по уровню. Память о последней позиции игрока - 4 с. Состояния: патруль между двумя точками (путь A*),
  тревога (0.5 с, поворот к источнику), погоня (путь A*, пересчёт раз в 0.6 с), замах ближнего удара
  (0.6 с, урон 12), стрельба с разбросом (дистанция 4.5-24 м, урон 7, перезарядка 1.2 с), нокдаун (1.2 с),
  смерть. Застревание: если тело не движется 1.5 с, путь пересчитывается.
- **Турель** (80 HP). Стоит на колонне, при виде поворачивается и стреляет (дистанция 30 м, перезарядка 1.4 с).
- **Навигация**: сетка 1 м по верхним поверхностям (луч сверху, стены выше 3 м непроходимы). Переход
  между клетками при подъёме не больше 0.45 м, по диагонали без срезания углов. Поиск A* с двоичной кучей.

## Уровень «Полигон»

Арена 60x60 м: стена для бега (8 м, вдоль оси Z), башня с уступом (2 м), перила (верх 1.08 м, над ними
два столба), балкон (1.6 м) с рампой, ящики-укрытия, колонна турели. Два пехотинца и турель.
Описание в `game/src/GameLayout.pas`; уровень - отдельный модуль, его можно заменить.

## Проверка

- `./build.sh` запускает `test_game`: 79 проверок. Темы: лучи по уровню, движение и прыжок, бег по стене
  и отскок, уступ с выстрелом и подтягиванием, сальто, цепочка прыжков, подкат, удар сверху, перила,
  зрение и линия видимости врагов, ближний удар, стрельба и смерть врага, навигация A*, камера у стены,
  детерминизм (одинаковый ввод даёт побитово одинаковое состояние), возрождение.
- Снимки сценариев (`docs/SCREENSHOTS.md`): бэкфлип и бег по стене просмотрены. Остальные сценарии
  выполняются без ошибок, их кадры не сверялись глазами.
- Бенчмарк игры: `./build.sh bench` (раздел в `docs/BENCHMARK.md`).

## Ограничения

- Окно GLFW не запускалось: в среде нет GLFW и GPU. Управление с клавиатуры проверено только кодом.
- Нет звука, шрифта (счётчик и здоровье - полосы и квадраты), меню, сохранений; один уровень.
- Персонажи собраны из примитивов, позы процедурные (нет скелетной анимации). Рэгдолл для врагов не используется:
  павший лежит на боку.
- Прицел: выстрел идёт по лучу камеры, прицеливания через плечо нет.
- Противники не прыгают: переходы возможны только по ступеням и рампам до 0.45 м (расчёт навигации).
- Производительность на процессоре: см. `docs/BENCHMARK.md`; нагрузка на GPU не измерялась.
