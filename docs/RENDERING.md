# Рендеринг: BRDF и конвейер в стиле Fox Engine

Документ описывает, что реализовано в шейдерах и проходах рендерера (`shaders/`, `src/render/EngRender.pas`),
что взято из публичных материалов о Fox Engine и чего в нём нет. Исходный код Fox Engine недоступен,
поэтому "похожесть" - это воспроизведение общих приёмов из публикаций, а не копия движка.

## Диффузная часть: три модели

Выбор задаётся полем `TRenderer.DiffuseMode` (флаг `--brdf lambert|burley|oren` у `examples/Demo`).
По умолчанию - Burley.

| Модель | Формула (множитель к albedo, включая 1/PI) | Свойство |
|---|---|---|
| Lambert | `1/PI` | эталон |
| Burley (Disney, 2012) | `(1 + (FD90-1)(1-NdL)^5)(1 + (FD90-1)(1-NdV)^5) / PI`, `FD90 = 0.5 + 2 r LdH^2` | при нормальном освещении и взгляде равна Lambert; у касательных углов ярче при большей шероховатости |
| Oren-Nayar (качественная модель) | `(A + B max(0, LdV - NdL NdV) / max(NdL, NdV)) / PI`, `A = 1 - 0.5 s/(s+0.33)`, `B = 0.45 s/(s+0.09)`, `s = r^2` | при шероховатости 0 равна Lambert; теряет энергию: при нормальном взгляде интеграл равен `A`, при r = 1 это 0.624 |

Формулы в `src/render/EngBRDF.pas` и `shaders/mesh.frag` одинаковые. Тесты (`tests/TestBRDF.pas`, 21 проверка):
предельные случаи (Oren-Nayar при r = 0 равен Lambert, Burley при нормальном падении равен 1/PI),
нормировка GGX (интеграл `D(NdH) NdH` по полусфере равен 1 для a = 0.1 ... 1), энергия диффузной части
по квадратуре, монотонность кривой тонемаппинга. Burley выбран по умолчанию, потому что при нормальном
освещении он сохраняет энергию, а качественная модель Oren-Nayar при больших шероховатостях заметно темнеет.

## Блик и материалы

- GGX: `D = a^2 / (PI ((NdH^2)(a^2-1)+1)^2)`, `a = r^2`.
- Видимость: высотно-коррелированная Smith (Heitz, 2014): `V = 0.5 / (NdL sqrt(NdV^2(1-a^2)+a^2) + NdV sqrt(NdL^2(1-a^2)+a^2))`.
- Fresnel: Schlick, `F0 = mix(0.04, albedo, metallic)`.
- Параметры на элемент: `Metallic`, `Roughness`, `Tint`, `Emission` (собственное свечение, для трассеров и вспышек).
- Окружение: полусферический свет (цвет неба/земли по нормали и по отражению). Локальных карт освещённости нет.

## Конвейер кадра

1. Карта теней направленного источника 2048x2048, PCF 3x3, смещение по нормали.
2. Основной проход в HDR (RGBA16F) с глубиной. Туман экспоненциальный, плотность падает с высотой.
3. Блум: выделение яркого (порог `Post.BloomThreshold`), четыре уровня понижения 2x2 и гауссово размытие
   (9 точек, разделяемое) по каждому уровню.
4. Композит в LDR (RGBA8): сложение блума, экспозиция, кривая Hable (Uncharted 2), гамма sRGB,
   насыщенность, контраст, разделение тонов (холодные тени, тёплые света), виньетка.
5. FXAA (упрощённая схема FXAA 3) на экран.

Значения по умолчанию: `RenderDefaultPost` (экспозиция 1, блум 0.06 при пороге 1.2, насыщенность 0.92,
контраст 1.06, виньетка 0.22, FXAA включён).

Исправлена ошибка, найденная визуально: тест глубины выключался постобработкой предыдущего кадра, и карта
теней на втором и следующих кадрах строилась неправильно (тень не отбрасывалась). Теперь тест включается в начале кадра.

## Что взято из публичных материалов о Fox Engine

- Линейное освещение, физически основанные материалы (альбедо, шероховатость, металличность), тонмаппинг
  стоит раньше LDR-постобработки: [Eurogamer, Digital Foundry: Tech Analysis MGS5 Fox Engine](https://www.eurogamer.net/digitalfoundry-tech-analysis-mgs5-fox-engine).
- Блум, FXAA, размытие движения, DOF, SSAO в два прохода, локальные irradiance-сферы, тонмаппинг в LDR:
  [Adrian Courrèges, Metal Gear Solid V - Graphics Study (2017)](https://www.adriancourreges.com/blog/2017/12/15/mgs-v-graphics-study/).
- Отложенное освещение, материалы по идентификатору, LUT-цветокоррекция, авто-экспозиция по диффузной части:
  обсуждение на [Reddit, r/metalgearsolid](https://www.reddit.com/r/metalgearsolid/comments/1vije73/fox_engine_material_id_systems_auto_exposure_and/).
- Список функций движка (физические материалы, view-dependent roughness, полупрозрачность кожи и волос):
  [Metal Gear Wiki, Fox Engine](https://metalgear.fandom.com/wiki/Fox_Engine).

## Что не реализовано

- Отложенное освещение (Fox - deferred lighting), SSAO, TAA, размытие движения, глубина резкости, авто-экспозиция.
- Локальные irradiance-сферы и материалы по идентификатору: здесь один полусферический окружающий свет.
- Цветокоррекция параметрическая, без LUT.
- Полупрозрачность кожи, волос и ткани.
- Проверка только программная (Mesa 21 softpipe, GL 4.3 через переопределение версии). Цвета и тени на реальном
  GPU не сверялись; различия между моделями BRDF в кадре малые, поэтому они видны на увеличенных фрагментах.

## Как воспроизвести

```sh
MESA_GL_VERSION_OVERRIDE=4.3 MESA_GLSL_VERSION_OVERRIDE=430 \
  ./build/examples/Demo --offscreen --osmesa /путь/libOSMesa.so.8 --frames 3 --brdf burley --shot out/demo_burley.png
./build.sh          # тесты, включая TestBRDF
```
