# engine - 3D-движок на FreePascal

Движок пишется на FreePascal (тулчейн собран из исходников, см. `docs/TOOLCHAIN.md`) в стиле без классов и объектов:
данные хранятся в записях (`record`), поведение - в процедурах и функциях, динамические массивы используются
только для геометрии и списков тел.

## Состав и текущий статус

| Подсистема | Модули | Статус |
|---|---|---|
| Математика | `src/engine/EngMath.pas` | готово, протестировано |
| Столкновения GJK + EPA | `src/engine/EngConvex.pas` | готово, протестировано (сферы, боксы, выпуклые оболочки) |
| Физика твёрдых тел | - | не начато |
| Анимация | - | не начато |
| Euphoria-подобное управление (активный рэгдолл) | - | не начато |
| Рендеринг OpenGL 4.3 и GLFW | - | не начато |
| Снимок экрана в PNG | - | не начато |
| Windows-порт, Lazarus-проект | - | не начато |

Пока готовы математика и столкновения. Остальные подсистемы описаны в плане ниже и будут добавлены отдельными модулями.

## Сборка и проверка

```sh
./build.sh            # сборка и тесты
./build.sh bench      # тесты + бенчмарки
./build.sh examples   # сборка примеров и инструментов
```

Компилятор берётся из `$FPC`, затем из `~/.local/fpc-3.3.1-dev/bin/fpc`, затем из `PATH`.
Оптимизация по умолчанию нацелена на AVX2 (`FPC_CPU_OPTS`, см. заголовок `build.sh`).

Сборка FPC из исходников: `FPC_SEED=/путь/к/ppcx64 tools/fpc/build_fpc_from_source.sh`.

## Структура

```
src/engine/     ядро: математика, столкновения (переносимый код без зависимостей от платформы)
tests/          тесты (запускаются build.sh)
bench/          бенчмарки подсистем
tools/fpc/      сборка FPC из исходников
docs/           документация, включая TOOLCHAIN.md
```

## Производительность (этот стенд)

Измерено на виртуальной машине 2 vCPU (Intel Xeon 2.6 ГГц), один поток, `./build.sh bench`.
Числа зависят от железа и не являются результатом для современных машин.

- сфера-сфера (аналитический путь): 0.09 мкс на пару;
- бокс-бокс, только GJK: 1.6 мкс на пару;
- бокс-бокс, GJK + EPA (с контактом): 5.7 мкс на пару;
- две выпуклые оболочки по 20 точек, GJK + EPA: 9.1 мкс на пару.

## Ограничения, которые важно знать

- Окружение, в котором велась разработка, не содержит GPU, драйвера OpenGL, X-сервера и системных GLFW/Mesa.
  Поэтому код рендеринга компилируется и проверяется статически (GLSL проверяется `glslangValidator`),
  но реальный рендер в этой среде не запускался. Снимки экрана пишутся тем же путём, что описан в
  <https://lencerf.github.io/post/2019-09-21-save-the-opengl-rendering-to-image-file/>, но на реальном GL не проверены.
- Компилятор 3.2.2 не собран (см. `docs/TOOLCHAIN.md`). Код пишется в переносимом подмножестве, но проверен на 3.3.1-dev.
- Windows-порт и Lazarus-проект будут описаны и подготовлены, но собрать их в этой среде нельзя (нет mingw и Lazarus).
